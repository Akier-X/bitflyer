## 🧠 売買ロジック詳細

### 買いシグナル (3種類)

| シグナル | 条件 | 説明 |
|---------|------|------|
| RSI買い | RSI < 42 & 急落中でない | 売られすぎで買いチャンス |
| モメンタム | トレンド > +0.3% & RSI < 65 | 上昇の波に乗る |
| 反発検知 | 下落→底→連続上昇パターン | V字回復を捉える |

### 売りシグナル (6種類・優先度順)

| 優先度 | シグナル | 条件 | 説明 |
|--------|---------|------|------|
| 1 | 緊急損切 | PnL ≤ -1.5% | いつでも即発動 |
| 2 | 急騰利確 | PnL ≥ +0.8% | 最低保有時間無視 |
| 3 | 通常利確 | PnL ≥ +0.6% & 45秒経過 | 目標利益達成 |
| 4 | 通常損切 | PnL ≤ -0.4% & 45秒経過 | 損失カット |
| 5 | トレーリング | PnL > +0.3% & 高値から-0.3% | 利益確保 |
| 6 | RSI売り | RSI > 58 & PnL > +0.2% & 60秒経過 | 過熱感で売り |

## 🔧 技術仕様

### クラス構成

```
Trader              メイントレーダー
├── BitFlyerClient  API通信 (ペアごと)
├── PriceAnalyzer   価格分析・RSI計算
└── Position        ポジション管理
```

### Position クラス
```python
@dataclass
class Position:
    pair: str           # 取引ペア
    size: float         # 保有数量
    entry_price: float  # 購入価格
    entry_time: datetime # 購入時刻
    highest: float      # 高値追跡 (トレーリング用)
```

### 安全機能

| 機能 | 実装 |
|------|------|
| 売却サイズ | 保有量の95%で計算 (残高誤差対策) |
| 数量丸め | math.floor() で切り捨て |
| 未決済キャンセル | 売却前に全注文キャンセル |
| API制限対策 | 残高30秒キャッシュ、価格取得1.5秒間隔 |
| エラー抑制 | 不要なログメッセージをフィルタ |
