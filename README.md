### 基本設定
```python

MIN_HOLD_TIME = 30           # 最低30秒保有

```

### AI信頼度
```python
AI_CONFIDENCE_THRESHOLD = 0.4  # 40%以上で取引
ML_WEIGHT = 0.3                # ML予測の重み
```

- ボラティリティに応じて利確/損切り幅を自動調整
- 連勝時は利確幅を拡大
- 連敗時は損切りを早める

## 📈 テクニカル指標詳細

### RSI (Relative Strength Index)
```
期間: 14
買いシグナル: RSI < 30 (売られすぎ)
売りシグナル: RSI > 70 (買われすぎ)
```

### MACD
```
短期EMA: 12期間
長期EMA: 26期間
シグナル: 9期間
買い: MACD線がシグナル線を上抜け
売り: MACD線がシグナル線を下抜け
```

### ボリンジャーバンド
```
期間: 20
標準偏差: 2σ
買い: 下限バンドにタッチ
売り: 上限バンドにタッチ
```

### 複数時間足
```
1分足: 短期トレンド
5分足: 中期トレンド
15分足: 長期トレンド
統合: 2つ以上が同方向でシグナル
```

## 🧠 機械学習予測

### LSTM風RNN
- 入力: 過去30価格データの変化率
- 隠れ層: 32ユニット
- 出力: 上昇/下落/横ばい確率
- オンライン学習: 100サンプルごとに自動更新

### パターン認識
| パターン | 方向 | 信頼度 |
|----------|------|--------|
| ダブルボトム | 買い | 70% |
| ダブルトップ | 売り | 70% |
| ヘッドアンドショルダー | 売り | 80% |
| 上昇トライアングル | 買い | 60% |
| ブレイクアウト | 方向依存 | 75% |

### アンサンブル予測
- 3つの異なるlookback期間 (20, 30, 50)
- 多数決 + 信頼度加重平均

## 📱 LINE通知

### 設定方法
1. [LINE Notify](https://notify-bot.line.me/ja/) でトークン取得
2. `.env` に追加:
```
LINE_NOTIFY_TOKEN=your_token_here
```

### 通知内容
- 🛒 購入完了通知
- 💰 売却完了通知 (損益表示)
- 📊 日次レポート (0時自動送信)
- 🎉 マイルストーン達成通知
- 🚀 起動/停止通知

### スマート通知
- 5分間隔で最大1通知
- ¥50以上の損益は即時通知
- 5取引ごとにサマリー通知

## 🚀 使用方法

### 1. 依存関係インストール
```bash
pip install -r requirements.txt
```

### 2. 環境設定
```bash
# .env ファイル作成
BITFLYER_API_KEY=your_api_key
BITFLYER_API_SECRET=your_api_secret
LINE_NOTIFY_TOKEN=your_line_token  # オプション
```

### 3. 実行

**v10.0 全機能版 (推奨)**
```bash
python -m src.bot.ultimate_trader
```

**v9.1 シンプル版**
```bash
python -m src.bot.aggressive_trader
```

### 4. 停止
```
Ctrl+C
```
